# Подводная каустика

Автор: junkky.

Остался только `/obj/effect/caustics/source` — невидимый источник света и радиального узора. Вариант от границ области удалён.

Узор проходит через прозрачные окна, блокируется непрозрачными стенами и рисуется только на полу, включая открытые треугольники диагонального сглаживания. Один фильтр обслуживает блок 4×4 клетки. Анимация: 64 кадра, цикл 5.12 секунды; проигрывается клиентом.

Настройки: `effect_range = 5` (1–12 клеток), `effect_alpha = 90` (0–255), `effect_color = "#72DCE8"`, `light_power = 0.6`. При `light_power = 0` остаётся только узор, видимый при освещении комнаты.

Геометрия рассчитывается после сглаживания при загрузке. После перемещения маркера, изменения настроек, стен или дверей нужен `rebuild()` маркера. Удаление маркера удаляет его эффекты.

`build_icons.py` пересоздаёт текстуру и проверяет бесшовность. `tests/masks.dm` проверяет радиальный градиент, кэш и маски диагонального пола.
