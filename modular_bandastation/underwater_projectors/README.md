# Подводный прожектор

Автор: junkky.

`/obj/effect/overlay/spotlight/underwater` — расширяющийся рассеянный конус с плавно движущейся взвесью и штатным направленным освещением. Взвесь встроена в DMI, который проигрывает клиент; кадры не обрабатываются сервером. Освещение использует обычные проверки видимости и затенения движка.

Ставьте в начало луча, например у внешнего края корпуса, и направляйте наружу через `dir`: N=1, S=2, E=4, W=8, NE=5, SE=6, NW=9, SW=10. Узкий конец находится в центре клетки размещения. На примере с двумя лучами по бокам корпуса используйте NW=9 слева и NE=5 справа.

- `beam_range = 6`: длина в клетках (0.5–12).
- `beam_width = 3`: полная ширина у дальнего конца (0.5–12).
- `color = "#8CDCE8"`: холодный голубой; `"#FFFFFF"` для белого.
- `alpha = 100`: яркость/прозрачность; 0 скрывает декор.
- `light_power = 1.5`: мощность настоящего света.
- `light_on = TRUE`: включает свет и луч; FALSE выключает оба.
- `show_particles = TRUE`: анимированная взвесь; FALSE оставляет статичный луч.
- `pixel_x` / `pixel_y`: исходные -208/-208 центрируют спрайт; меняйте для небольшого смещения точки начала.

После изменения размера, цвета или show_particles через VV вызовите `update_beam()`: дальность и угол настоящего света согласуются с конусом. `setDir()` обновляет поворот света и картинки автоматически. Смещение большого спрайта не смещает источник света с клетки крепления. Свет учитывает препятствия; декоративное изображение луча по-прежнему не обрезается стенами, поэтому размещайте его наружу от корпуса. Для темноты над океанским параллаксом используйте `/area/space/ocean` из модуля `underwater`.

Анимация: 48 кадров, цикл 4.8 секунды. `build_icons.py` (numpy + Pillow) пересоздаёт ассет и проверяет замыкание цикла, отсутствие света позади источника и выходящих за конус частиц. Все экземпляры используют одну текстуру; сервер не обрабатывает кадры.

StrongDMM использует `icons/projector_preview.dmi` с восемью направлениями: смена `dir` видна сразу. После обновления ассета перезагрузите проект/DME в редакторе. Предпросмотр статичный и показывает стандартный размер; `beam_range`, `beam_width` и анимация применяются при запуске игры. Runtime использует прежний однонаправленный DMI с поворотом через матрицу.
